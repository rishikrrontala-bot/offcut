# OFFCUT identity assets

Created October 11, 2026 using the built-in image generation tool. These are branding assets, not evidence of physical assembly or outputs from OFFCUT’s segmentation pipeline.

- offcut-wordmark.png: transparent horizontal master logo.
- offcut-icon-clean.png: final transparent square cut-paper symbol.
- offcut-icon.png: initial generated variant, superseded by the clean icon.
- offcut-devpost-cover.png: 1536 × 1024 (3:2) project thumbnail, under Devpost’s 5 MB limit.

The detached terra square represents a leftover piece finding a new place. Warm paper, ink and terra match DESIGN.md. Built by Rishik Rontala.

## Generation brief

Built-in image generation was used for a transparent lowercase ink wordmark, a transparent square symbol formed from four paper pieces with a detached terra piece, and a 3:2 warm-paper Devpost cover reading “offcut.” and “Make something from what’s left.” The final icon edit removed the stray pale mark while preserving the symbol. These assets follow the existing paper/ink/terra design world.
