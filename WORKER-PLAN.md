# OFFCUT — coding delegation plan

Actual external Featherless jobs ran after the time gate and Rishik’s instruction to continue under the published Image AI theme. Flash returned export code that root corrected and verified; larger GLM-5.3 jobs failed to return complete usable artifacts, so root completed the engine. No incomplete output was accepted as working code. The table below records the routing policy, not claims that every planned module came from an external worker.

Root owns integration, source review, browser verification and spend accounting. External GLM responses are proposals, not permission to execute arbitrary commands or modify files. Validate returned paths inside allowed source modules, reject secrets/unsafe commands/dependencies, review complete patches, then apply and test. Keep the harness and ledger outside public source under the parent .private folder. Do not send the API key or unrelated account/project context in prompts.

Keep one or two workers active, with separate file ownership. Include only current interfaces and relevant requirements. Use bounded completion limits and reserve worst-case input/output cost before every request. Reconcile returned token usage and account balance; retain reservations for ambiguous timed-out requests until reconciled rather than assuming they were free. Track exact nano-USD, rate version, task, model, request identifier and usage. Do not automatically retry endless failures; cheaper-worker escalation must follow a concrete failed check.
